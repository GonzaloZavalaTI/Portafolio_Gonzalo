	Para generar un Enlace Tunelizado para sacar una pagina Web de forma local al Internet
1. Levantamos el Live Server en Visual Studio Code, sacamos el puerto 5500

2. Descargamos desde PowerShell CloudFlared

winget install Cloudflare.cloudflared

3. En otra terminal sin cerrar la anterior, ejecutamos

cloudflared tunnel --url http://localhost:8000

4.Obtenemos el enlace

https://par-string-monitored-material.trycloudflare.com/
